# Portfolio Agent Instructions

## Project Context

This project is a modern product design portfolio focused on clarity, systems thinking, usability, and premium visual execution.

The portfolio should communicate:
- Product maturity
- Strategic thinking
- Strong UX foundations
- Design systems knowledge
- Clean implementation quality

The experience should feel intentional, calm, editorial, and minimal.

Avoid overly experimental or visually excessive interfaces.

---

# Design Philosophy

Prioritize:
- Clarity over decoration
- Structure over visual complexity
- Readability over density
- Consistency over novelty
- Spacing and hierarchy over heavy styling

The interface should feel refined and understated rather than trendy.

---

# Visual Direction

The visual style should:
- Use minimal color usage
- Rely heavily on typography hierarchy and spacing
- Maintain a premium editorial aesthetic
- Use restrained motion and subtle interactions
- Preserve strong alignment and layout rhythm

Avoid:
- Excessive gradients
- Over-animation
- Visual clutter
- Glassmorphism-heavy UI
- Random decorative elements
- Overly playful layouts

---

# Typography Direction

Typography is a primary design element in this project.

Requirements:
- Maintain strong hierarchy
- Use spacious line heights
- Preserve readability across screen sizes
- Use typography rhythm consistently
- Avoid excessive font-weight variation

Typography should feel calm, modern, and structured.

---

# Layout Principles

- Use grid-based responsive layouts
- Preserve consistent spacing between sections
- Maintain strong whitespace usage
- Avoid overcrowded interfaces
- Prioritize scanability and visual rhythm

Sections should breathe.

The portfolio should feel premium through restraint and spacing rather than visual effects.

---

# Component Principles

Components must:
- Be reusable
- Be visually consistent
- Use shared design tokens
- Preserve consistent interaction patterns

Buttons, cards, navigation, and containers should feel unified across the experience.

Avoid inconsistent styling between sections.

---

# Interaction Principles

Interactions should feel:
- Fast
- Smooth
- Subtle
- Intentional

Use minimal transitions and restrained hover states.

Avoid excessive animation or distracting movement.

Motion should support usability, not dominate attention.

---

# Responsive Behavior

The portfolio must scale effectively across:
- Desktop
- Tablet
- Mobile

Requirements:
- Preserve readability
- Maintain spacing consistency
- Prevent layout breaking
- Avoid horizontal scrolling
- Maintain hierarchy across breakpoints

---

# Accessibility Standards

Maintain:
- Accessible contrast ratios
- Readable typography
- Clear interactive states
- Semantic structure
- Keyboard accessibility where applicable

Accessibility should be treated as a core product quality requirement.

---

# Implementation Priorities

Priority order:
1. Layout structure
2. Typography hierarchy
3. Spacing consistency
4. Responsiveness
5. Accessibility
6. Interaction polish
7. Visual enhancement

Visual styling should never compromise usability or clarity.

---

# Content Presentation

Project and case study content should:
- Be concise
- Be easy to scan
- Highlight outcomes and impact
- Use strong hierarchy
- Avoid dense text blocks

The interface should support storytelling without overwhelming the user.

---

# System Rules

- Use provided design tokens consistently.
- Do not introduce arbitrary styling values.
- Reuse established spacing, radius, and typography variables.
- Maintain visual consistency across all sections and components.

Consistency is more important than visual variety.

---

# Experience Goal

The final portfolio experience should feel:
- Minimal
- Strategic
- Confident
- Modern
- Editorial
- Product-focused
- Technically mature

The portfolio should reflect the mindset of a product designer who understands systems, usability, and scalable digital experiences.
