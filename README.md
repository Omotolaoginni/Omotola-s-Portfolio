A modern product design portfolio focused on clean interfaces, scalable design systems, thoughtful user experiences, and structured visual storytelling.

This project is built as a system-driven portfolio that combines:
- editorial-style presentation
- token-based design architecture
- reusable UI patterns
- responsive layouts
- accessibility-first thinking
- AI-assisted UI generation workflows

The portfolio showcases:
- product design work
- UX thinking
- design systems
- interface audits
- visual hierarchy
- case study storytelling

The goal is to create a calm, refined, and production-ready digital experience.

# Design System

The portfolio is powered by a structured design system.

The single source of truth for all visual tokens is:

- `design-tokens.tokens.json`

The token system defines:
- colors
- spacing
- typography
- radius
- interaction behavior
- focus states
- surface hierarchy

No arbitrary styling should bypass the token system.

# Design Token Workflow

- `design-tokens.tokens.json`

- spacing tokens
