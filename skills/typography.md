# Typography Rules
This doumeent defines the typographic system used throughout this application

The system follows the princciples influnced by the Material Design typography scale

## Obejectives
Typography provides:
Clear Hierachy 
Consistent reading
comfortable scanning

## Font Family
Primary UI Font: Inter

Fallback fonts:
apple - system
system - ui
sans- serif
Arial
Roboto

## Type Scale
use the type scale in the design tokens

## Usage guidelines
Page display text should use Display Large
section titles should use headline large
Button labels should use label large 
Form labels should use label medium or label large 
Standard paragraphs and body text should use body large 
Card titles should use title medium 

## Accessibility
All text size must be measured in rems not pxels
All heading and display text must use clamp function in css
Low contrast text ccombination are avoided
Text placed on colored surfaces uses the matching "on-*" color token
