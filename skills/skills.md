# Portfolio Project Rules & Standards

## General Design Rules

- Maintain a minimal and modern visual style throughout the portfolio.
- Prioritize clarity, hierarchy, readability, and spacing over decorative visuals.
- Use consistent spacing, alignment, and layout structure across all sections.
- Avoid cluttered interfaces or excessive visual noise.
- Maintain a premium editorial feel with strong typography hierarchy.
- Ensure all sections are visually balanced and easy to scan.

---

# Layout & Structure Rules

- Use a responsive grid-based layout system.
- Maintain consistent spacing between sections and components.
- Ensure layouts scale properly across desktop, tablet, and mobile devices.
- Avoid overcrowded content containers.
- Preserve strong visual rhythm throughout the interface.
- Use whitespace intentionally to improve readability and focus.

---

# Typography Rules

- Use Onest as the primary typeface throughout the portfolio.
- Maintain consistent typography hierarchy across all pages.
- Limit typography weights to maintain visual consistency.
- Ensure body text remains highly readable across all screen sizes.
- Avoid excessive font-size variation.
- Use clear heading structure for accessibility and scanability.

---

# Color System Rules

-# Design Token Rules

- All colors, typography, spacing, radius, and visual primitives must be sourced from the provided design token system.
- Do not introduce arbitrary colors outside the token definitions.
- Maintain consistent usage of semantic tokens across all components and layouts.
- Interactive states such as hover, active, focus, and disabled states must use defined token values.
- Ensure token usage remains scalable and reusable throughout the system.
- Preserve visual consistency between sections and components by relying on shared token values.

---

# Component Rules

- Components must be reusable and visually consistent.
- Maintain consistent padding, spacing, and border radius values.
- Buttons, cards, navigation, and tags should follow shared styling patterns.
- Ensure hover and active states remain subtle and modern.
- Avoid inconsistent component styling across pages.

---

# Interaction & Motion Rules

- Use subtle motion and transitions only where necessary.
- Hover interactions should feel smooth and intentional.
- Avoid excessive animation or distracting motion.
- Maintain fast and responsive interaction feedback.
- Preserve a calm and premium browsing experience.

---

# Accessibility Rules

- Maintain accessible color contrast ratios.
- Ensure text remains readable across all devices.
- Support keyboard navigation where applicable.
- Use semantic heading structure for accessibility.
- Interactive elements must remain clearly identifiable.

---

# Responsive Design Rules

- The portfolio must function seamlessly across:
  - Desktop
  - Tablet
  - Mobile
- Content should reflow naturally across breakpoints.
- Avoid horizontal scrolling issues.
- Preserve spacing and hierarchy on smaller screens.

---

# Naming Conventions

- Use clear and scalable naming for sections and components.
- Maintain consistent naming patterns across reusable elements.
- Use descriptive naming for design tokens and variables.
- Avoid ambiguous or inconsistent labels.

Examples:
- button-primary
- project-card
- section-heading
- text-body-large

---

# Content & Case Study Rules

- Prioritize concise and impactful storytelling.
- Highlight measurable outcomes where possible.
- Keep project descriptions easy to scan.
- Use strong hierarchy between titles, metadata, and descriptions.
- Avoid overly dense paragraphs.

---

# Performance & Optimization Rules

- Optimize layouts for fast loading and responsiveness.
- Avoid unnecessary visual complexity that affects performance.
- Keep interactions lightweight and smooth.
- Ensure image assets remain optimized.

---

# Product Safety & Quality Rules

- Maintain consistent UI quality across all pages.
- Avoid broken layouts or inconsistent spacing behavior.
- Ensure all interactive elements function correctly.
- Preserve visual consistency between sections.
- Prevent accessibility regressions during iteration.

---

# Testing Expectations

- Test layouts across multiple screen sizes.
- Validate spacing and alignment consistency.
- Verify readability and accessibility standards.
- Ensure hover and interaction states behave correctly.
- Review responsiveness before final implementation.
- Ensure all navigation and CTA interactions function properly.

---

# Experience Principles

The portfolio experience should feel:
- Minimal
- Strategic
- Editorial
- Modern
- Calm
- Intentional
- Premium

The final experience should communicate strong product thinking, visual clarity, and systems-level design execution.
